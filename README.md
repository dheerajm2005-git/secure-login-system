# Secure Login System

A simple secure login web application built with Flask, SQLite, and bcrypt.

## Features

- User registration
- Secure password hashing using bcrypt
- User login and password verification
- Basic input validation
- Parameterized SQL queries to help prevent SQL injection
- Session-based authentication
- Logout functionality
- Protected dashboard
- SQLite database for storing user accounts

## Technologies Used

- Python
- Flask
- SQLite
- bcrypt
- HTML
